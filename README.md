# Quote-Generator-4

Quote Generator built with HTML, CSS and JavaScript.

A small, responsive web app that shows a random quote and lets users generate new quotes on demand. This repo contains a simple single-page implementation (index.html) with styling (style.css) and the JavaScript logic (script.js).

## Features

- Minimal, mobile-friendly UI
- Generates a new random quote on button click
- Clean, simple code that's easy to read and extend

## Files

- `index.html` — HTML markup and structure
- `style.css` — Styling and layout
- `script.js` — Quote generation logic
- `Screenshot 2024-08-12 145317.png` — App screenshot used in this README

## Run locally

1. Clone the repository

   git clone https://github.com/BinaryVortex/Quote-Generator-4.git
2. Open `index.html` in your web browser (double-click or `Open File` in your browser).

No build tools or dependencies required.

## Usage

- Click the "New Quote" button to get a random quote.
- You can open the browser console to inspect the data or modify the list of quotes in `script.js`.
